# Contribuire a NODUS

## Prima di iniziare
- Leggere il README e i documenti in `docs/`.
- Verificare le decisioni aperte e gli ADR esistenti.
- Discutere modifiche che impattano il modello dati o i flussi prima di implementarle.

## Modifiche
- Mantenere le modifiche focalizzate.
- Aggiornare la documentazione quando cambiano comportamenti o regole.
- Aggiungere test per le regole di business.
- Non inserire credenziali, dati reali di clienti o informazioni riservate nel repository.

## Pull request
Ogni pull request dovrebbe indicare:
- Obiettivo e contesto.
- Moduli interessati.
- Modifiche al modello dati o alle API.
- Test eseguiti.
- Documentazione aggiornata.
