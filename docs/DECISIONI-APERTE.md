# Decisioni aperte — NODUS

Questo documento raccoglie le scelte da validare prima o durante lo sviluppo. Quando una decisione ha impatto architetturale, registrarla anche come ADR in `docs/decisioni/`.

## Prodotto e organizzazioni
- [ ] NODUS sarà un servizio multi-tenant con abbonamento?
- [ ] Uno store o laboratorio può avere più sedi?
- [ ] Un utente può lavorare per più organizzazioni?
- [ ] Sono previsti collaboratori esterni?

## Preventivi e lavorazioni
- [ ] Un preventivo contiene una o più lavorazioni?
- [ ] È possibile accettare solo alcune voci di un preventivo?
- [ ] Più laboratori possono contribuire allo stesso preventivo?
- [ ] Come vengono gestite le revisioni e le scadenze?
- [ ] Come vengono autorizzati costi aggiuntivi?

## Logistica e responsabilità
- [ ] Chi registra spedizioni e trasferimenti?
- [ ] È necessario tracciare consegna e presa in carico tra laboratori?
- [ ] È richiesta una conferma di ricezione dell'oggetto?
- [ ] Come si gestiscono smarrimenti, danni e contestazioni?

## Inventario e attrezzature
- [ ] I ricambi sono gestiti per singolo laboratorio e sede?
- [ ] Le lavorazioni devono verificare disponibilità di ricambi e attrezzature?
- [ ] È previsto un magazzino condiviso?
- [ ] Come si gestiscono lotti, seriali e soglie di riordino?

## Tecnologia e gestione
- [ ] Web app, app mobile o entrambe?
- [ ] Stack frontend e backend?
- [ ] Database e sistema di archiviazione allegati?
- [ ] Hosting, backup e monitoraggio?
- [ ] Sistema di notifiche?
- [ ] Strategia di test e rilascio?
